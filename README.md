## 💻 Getting Started
1. Clone the repository.
```bash
git clone https://github.com/diro25/daily-python-practice.git
```
2. Navigate to the project folder.
```bash
cd daily-python-practice
```
3. Run any file.
```bash
python day01_variables.py
```
